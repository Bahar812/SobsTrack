# UI Dashboard (Halaman)

## 1. Login
- Form email + password
- Role-based redirect (Admin/Sales)

## 2. Dashboard Home
Komponen utama:
- Kartu ringkasan: total absensi hari ini, aktivitas hari ini, leads aktif, SPK bulan berjalan, stok tersedia
- Ranking sales berdasarkan SPK bulan berjalan
- Grafik ringkas: tren SPK 4 minggu terakhir

## 3. Absensi & Kebersihan
- Form check-in: lokasi (GPS/text), foto selfie
- Form check-out
- Upload foto kebersihan (1-3 foto)
- Tabel rekap (admin): filter sales & cabang

## 4. Daily Activity
- Form input aktivitas: WA Story, FB Marketplace (min 3), TikTok
- Upload bukti (screenshot/link)
- Statistik harian & bulanan

## 5. Leads (CRM)
- Table leads dengan filter sales, status, tanggal
- Drawer/Modal detail lead
- Update status & catatan follow-up

## 6. Kalender Mingguan
- Weekly calendar view
- Event card: nama, waktu, cabang, lokasi
- Form tambah/edit event

## 7. SPK / DO
- Tabel SPK (admin)
- Ringkasan target vs realisasi
- Ranking sales (SPK bulan berjalan)

## 8. Dokumen
- List dokumen per kategori
- Download untuk sales
- Upload untuk admin

## 9. Harga OTR
- Table harga (brand, tipe, cabang, last updated)
- Admin: inline edit/update

## 10. Stok Unit
- Table stok unit (status booking/available)
- Filter cabang & status

## Layout Umum
- Sidebar navigasi
- Topbar: nama user, cabang
- Konten responsif (mobile stack)
